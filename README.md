## Description

NetMessenger is a multi-client chat and file-sharing platform implemented in C using the BSD sockets API over TCP/IP.

The system consists of a server and multiple clients. It supports user registration, broadcast messaging, private messaging, chat rooms, file sharing, graceful disconnection, error handling, and server-side logging.
